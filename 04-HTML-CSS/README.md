# 04 — HTML & CSS Essentials

You do not need to become a designer, but you must be able to build and understand a clean responsive interface.

## HTML

- Semantic elements
- Forms
- Inputs and validation
- Tables
- Accessibility basics
- Metadata

## CSS

- Selectors
- Box model
- Display
- Flexbox
- Grid
- Positioning
- Responsive design
- Media queries
- Basic transitions

## Real Case

Build the cafe menu page: responsive product cards, category navigation, cart summary and checkout form.

## Exercises

- Recreate a login page.
- Build a responsive navbar.
- Build product cards.
- Build a responsive cafe menu.
- Make a checkout form accessible.
