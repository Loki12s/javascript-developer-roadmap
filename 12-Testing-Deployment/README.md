## Real Case

A customer says checkout fails. Your job is to reproduce it, inspect the network request, read the server error, isolate the failing function, fix it, test it, and deploy safely.

## Practice

- Debug five broken JavaScript programs.
- Test API success and failure responses.
- Write tests for cart totals and discount calculations.
- Deploy a small frontend and backend project.
