# 14 — Coding Practice

Solve problems in JavaScript and explain your approach before coding.

## Level 1

- Reverse a string
- Palindrome
- Count characters
- Find max/min
- Sum an array
- Remove duplicates
- FizzBuzz

## Level 2

- Two Sum
- Frequency counter
- Group products by category
- Flatten an array
- Sort objects by price
- Find duplicate orders
- Calculate cart totals

## Level 3

- Debounce
- Throttle
- Implement a simple cache
- Promise-based retry
- Pagination helper
- Build a small event emitter

## Rule

For every problem: understand → example → brute force → improve → code → test edge cases → explain complexity.
