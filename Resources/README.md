## Recommended Order

1. Follow the repository theory.
2. Watch the linked video for the same concept.
3. Re-type the examples.
4. Complete the exercises.
5. Build the related real-world feature.
6. Answer the interview questions without notes.

## Resource Quality Rule

Prefer official documentation for exact behavior and APIs. Use videos when you need a visual explanation or guided build. Avoid collecting dozens of courses; finish one learning path before switching.
