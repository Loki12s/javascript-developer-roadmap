# 15 — Interview Preparation

## JavaScript Theory

Prepare clear answers for:

- `var`, `let`, `const`
- primitive/reference values
- scope and hoisting
- closures
- `this`
- prototypes
- promises
- async/await
- event loop
- array methods
- modules
- DOM events

## Browser

- DOM
- event bubbling/delegation
- localStorage
- HTTP
- CORS
- cookies

## Backend

- Node.js runtime
- Express middleware
- REST design
- status codes
- validation
- authentication/authorization
- SQL joins and transactions

## React

- components
- props/state
- rendering
- hooks
- effects
- forms
- API integration

## Project Interview

Be able to explain your project without reading the README:

1. What problem does it solve?
2. Why did you choose the architecture?
3. How does data flow from UI to database?
4. How is authentication handled?
5. What was the hardest bug?
6. How did you test it?
7. What would you improve with more time?

## Mock Interview Rule

Record yourself answering five questions every week. If the explanation is unclear, revisit the concept.
