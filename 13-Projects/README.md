## Project 3 — Cafe QR Ordering System ⭐

### Customer side
- Scan QR
- Browse menu
- Search/filter
- Add to cart
- Place order
- Track order status

### Staff side
- Login
- View orders
- Accept/reject order
- Update preparation status
- Manage products

### Technical stack
React + Node.js + Express + SQL + authentication.

### Real-world flow
`QR → menu → cart → POST /orders → database → kitchen dashboard → status update → customer sees status`
