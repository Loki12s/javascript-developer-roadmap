# 08 — REST APIs

## Learn

- Resources and endpoints
- GET, POST, PUT, PATCH, DELETE
- HTTP status codes
- Headers
- JSON request/response
- Query parameters
- Pagination
- Filtering and sorting
- Validation
- Error response design
- API versioning basics

## Real Case

Design an order API:

- `GET /api/menu`
- `POST /api/orders`
- `GET /api/orders/:id`
- `PATCH /api/orders/:id/status`
- `DELETE /api/orders/:id`

Think about validation, permissions, errors and what data should be returned.

## Exercises

Use Postman or another API client to test every endpoint. Write down expected request body, response body, status code and error cases.
