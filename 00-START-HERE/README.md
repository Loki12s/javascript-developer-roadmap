# 00 — START HERE

## Goal
Become capable of building and explaining JavaScript applications for an entry-level developer role.

## Before You Start

Install:
- VS Code
- Node.js LTS
- Git
- A modern browser such as Chrome or Edge

## Daily Routine

**90–120 minutes:**
1. 20 min theory
2. 25 min video/documentation
3. 40 min coding from memory
4. 20 min exercises
5. 10 min notes/interview questions

## Golden Rule

Never copy a solution immediately. First predict the output, then run it. If it fails, read the error and debug it.

## Learning Loop

Learn → Code → Break → Debug → Explain → Practice → Build.

## Progress

- [ ] JavaScript fundamentals

- [ ] HTML/CSS
- [ ] Git/GitHub

## First Rule

Do not rush into React. Strong JavaScript fundamentals make React, Node.js and debugging much easier.
