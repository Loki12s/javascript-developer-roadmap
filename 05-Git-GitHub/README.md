# 05 — Git & GitHub

## Learn

- Repository basics
- `clone`, `status`, `add`, `commit`, `push`, `pull`
- Branches
- Merge and conflict resolution
- Pull requests
- `.gitignore`
- Meaningful commit messages
- README writing

## Real Case

Work on a cafe ordering feature in a branch, commit small changes, merge them safely, and recover from a bad change.

## Practice

Create a repository for every major project. Make at least 10 meaningful commits while building it.
